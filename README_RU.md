# ESP32 NAT Router: W5500, USB 4G-модем и AmneziaWG

Основа: [martin-ger/esp32_nat_router](https://github.com/martin-ger/esp32_nat_router), коммит
`08da293` (v2.4.23), с полной историей. У оригинала нет файла лицензии: его код принадлежит автору.
Лицензия на добавленные здесь изменения пока не выбрана.

Плата: **Waveshare ESP32-S3-ETH / ESP32-S3-POE-ETH(-M)** (ESP32-S3R8, 8 МБ PSRAM, 16 МБ flash,
WIZnet W5500).

## Ethernet через W5500

Апстрим умеет Ethernet только через встроенный RMII-контроллер оригинального ESP32 (WT32-ETH01,
LAN8720). У ESP32-S3 такого контроллера нет, поэтому Waveshare ставит внешний SPI-чип W5500:

| Сигнал | MISO | MOSI | SCLK | CS | RST | INT |
|---|---|---|---|---|---|---|
| GPIO | 12 | 11 | 13 | 14 | 9 | 10 |

W5500 получает MAC-адрес самого ESP32: собственного у него нет. В menuconfig ("NAT Router Uplink"
→ "Uplink device") выбирается LAN8720 или W5500; на чипах без RMII доступен только W5500.

## USB 4G-модем

| Режим | Окружение | Модемы | Драйвер Espressif |
|---|---|---|---|
| PPP / AT-команды | `esp32-s3-usb-modem-ppp` | Quectel EC20/EC25, SIMCom A76xx, Air780E, Fibocom LE270 и др. | `iot_usbh_modem` |
| Сетевая карта | `esp32-s3-usb-modem-net` | Huawei E3372h (HiLink) и др. модемы с веб-интерфейсом 192.168.8.1 | `iot_usbh_rndis` / `iot_usbh_ecm` |

- **PPP:** модем дозванивается сам. APN задаётся в `CONFIG_USB_MODEM_APN`, если без него не работает.
  Модем не из встроенного списка добавляется через `CONFIG_USB_MODEM_CUSTOM_VID/PID`.
- **Сетевая карта:** по умолчанию RNDIS, для CDC-ECM укажите `CONFIG_USB_MODEM_NET_ECM=y`.
- **Подключение:** нативный USB чипа (GPIO19 = D−, GPIO20 = D+): разъём USB-C через OTG-переходник
  или выводы IO19/IO20. Модему нужно 5 В и до 2 А; проверьте, что 5 В доходит до VBUS.
- **Консоль** переезжает на UART0: TX = IO43, RX = IO44, 115200. Прошивать по USB-C можно, но в
  загрузчик придётся входить вручную: зажать BOOT, нажать RESET.
- **Скорость:** USB у ESP32-S3 только Full Speed, реально около 8–10 Мбит/с.
- **PPP:** счётчик трафика, ACL и захват пакетов работают и на стороне uplink. VJ-сжатие
  выключено: NAT на PPP отбрасывает такие пакеты.

Модемный код лежит в отдельном компоненте `usb_modem_components/` и подключается только
модемными окружениями.

## AmneziaWG

Наряду с WireGuard: `Jc`, `Jmin`, `Jmax`, `S1`–`S4`, `H1`–`H4` (числа или диапазоны) и `I1`–`I5`.
Вставьте `.conf` целиком на странице VPN, параметры определятся сами. Протокол переключается там
же или командой `set_vpn -P 0|1`. При неверных параметрах туннель не поднимается: откатиться на
обычный WireGuard без маскировки прошивка не пытается.

Не поддерживаются новые опции `amneziawg-go`: `header_protection_key`, `random_trailers`,
`content_padding_addition`. Библиотека WireGuard лежит в `components/esp_wireguard`, изменения
описаны в `VENDORED.md`. Основа — esp_wireguard 0.9.2 с исправлениями уязвимостей (GHSA).

## Настройки платы Waveshare

Файл `sdkconfig.defaults.waveshare_s3_eth`, таблица `partitions_16mb.csv` и секция
`[waveshare_s3_eth]` в `platformio.ini`:

- 16 МБ flash: два раздела по 4 МБ для обновлений, NVS 64 КБ, хранилище ~7,8 МБ, раздел для дампа
- 8 МБ PSRAM, в том числе для буферов Wi-Fi и сети
- таблица NAT на 1024 записи, до 10 Wi-Fi-клиентов
- RGB-светодиод WS2812 на GPIO21, сброс настроек кнопкой BOOT (5 секунд)

На платах с меньшим объёмом flash эти настройки работать не будут.

## Диагностика

Причина последней перезагрузки пишется в лог при старте и видна в `show status`. После падения
дамп памяти сохраняется во flash, в разделе `coredump`.

## Сборка

```bash
pio run -e esp32-s3-eth-w5500 -t upload   # Ethernet через W5500
pio run -e esp32-s3-usb-modem-ppp         # USB-модем, PPP
pio run -e esp32-s3-usb-modem-net         # USB-модем, сетевая карта
pio run -e esp32-s3-eth-wifi-uplink       # интернет от другой сети Wi-Fi, WPA2-Enterprise
```

Источник интернета пока выбирается при сборке, а не в настройках.

## Статус

- **Проверено на плате:** сборка `esp32-s3-eth-w5500`. W5500 получает адрес по DHCP, NAT для
  Wi-Fi-клиентов работает, PSRAM определяется, светодиод показывает правильные цвета.
- **Известная проблема:** телефон Android в Wi-Fi роутера не открывает веб-интерфейс, хотя
  интернет через роутер работает.
- **AmneziaWG проверен на компьютере:** код WireGuard из прошивки против эталонного сервера
  `amneziawg-go`. Рукопожатие и трафик проходят для WireGuard, AmneziaWG 1.0 и полного профиля
  (`S1`–`S4`, диапазоны `H`, `I1`–`I5`); при несовпадающих параметрах сервер отказывает. На плате
  и с реальным сервером не проверялось.
- **Не проверялись:** сборки с USB-модемом и сборка с Wi-Fi uplink.
- Все четыре окружения собираются в PlatformIO 6.13 (ESP-IDF 5.5.3).
